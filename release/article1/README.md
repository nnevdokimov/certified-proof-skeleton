This directory publishes a compact, derived summary of the completed native-method check and its descriptive network profiles. It contains no manuscript, target formulae, raw trajectories, or personal contact information.

## What the results establish

The working configuration combines certified cumulative growth, learned half-selection on its supported syntax, deferred replay, reversible activity pruning, positive-marginal proof coding, and a **fixed** structural rule repertoire. Search permissions remain separate from proof support. The frozen continuation test measures subsequent coverage of a common initially uncovered target set, rather than rewarding initial library size.

The registered check completed **16 source blocks, 160 continuations, and 963 held-out targets**. Its independent audit replayed **4,174,478 admission events** and checked **2,846** recoveries of previously hidden support. These counts describe work across trajectories, not distinct mathematical theorems.

The registered conclusion remains `no_confirmed_adaptive_superiority`. Adaptive selection averaged 0.0625 more newly covered residual targets than fixed selection at each registered endpoint; all three Holm-adjusted comparison values equal 1.0. Fixed supplies a reproducible working configuration, not a proof of optimality. The test neither establishes adaptive superiority nor establishes equivalence.

Network profiles describe the initial delivered libraries, not future proof utility. The fixed representative follows the first source: **675 derived anchors, 29 roots, and 137 proof-support nodes**, hence **841 vertices and 1,573 directed arcs**. The package also retains all 16 fixed and 16 adaptive profiles, plus the compatible Metamath fragment and two representations of the complete finite H3 slice. Matching the basis does not match proof depth, context, granularity, or computational budget.

## Reproduction boundary

**This directory is not the complete immutable data archive.** It supports inspection of reported aggregates, comparison of their source hashes, and deterministic re-export when the original local packages are available. It does not contain enough data to replay the proof audit, rebuild every trajectory, or independently refit every graph.

The exporter reads the original packages under the repository-relative `output/` locations recorded in `provenance.json`. It verifies receipt and audit links and the selected input hashes; it does not repeat the original independent scientific audit. Missing source packages stop export rather than silently replacing evidence. Obtain the full archived packages before attempting scientific reproduction; their hashes do not imply that a public archive already exists.

With those original packages available, run from the repository root:

```sh
python3 release/article1/export_summary.py --check
```

To regenerate the compact files after verifying the same sources, omit `--check`. The exporter does not launch generation, evaluation, network fitting, cluster jobs, or publication. Never rewrite a sealed package to accommodate this export.

The historical technical amendment occurred before the first target scoring and used the same held-out corpus; it does not constitute an independent replication. The declared CPU boundaries include measured operational components, not all historical library/model costs, interpreter startup, offline observation, or the final audit. No end-to-end speed-up follows from this compact holdout comparison alone.
